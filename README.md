Island Courier is an original 3D flight game: fly a little red-and-white mail plane across a tropical archipelago, thread eight glowing gold rings and land gently on island strips to make three deliveries — while fuel burns, hard landings bend the airframe, and the clock charges by the second. Built with vendored Three.js, a hand-built plane and terrain, a glowing instrument HUD, and fully synthesised WebAudio sound. No network requests, no build step.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Fly with W/S to pitch, A/D to bank and turn, Shift/Ctrl for throttle, drag the mouse to look around, P to pause, R to restart, M to mute. Screenshot poses: `?shot=start|play|ring|end&seed=N`.
